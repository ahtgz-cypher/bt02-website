NĂNG LỰC & KỸ NĂNG CHUYÊN MÔN

SKILLS MATRIX // 02

Đọc & Phân Tích Log Chuyên Sâu

Log Analysis & Forensics
  • Windows Event Logs: Phân tích bảo mật với Event ID 4624 (Logon), 4625 (Failed Logon), 4688 (Process Creation), 4720, 1102...
  • Linux Syslog: Thành thạo tra cứu /var/log/auth.log, syslog, secure, SSH brute-force detection.
  • Web Server Logs: Phân tích log truy cập Nginx, Apache, nhận diện các mẫu quét cổng, SQL Injection, XSS, Path Traversal.
  • Forensics cơ bản: Điều tra số dấu vết tiến trình, thu thập bằng chứng kỹ thuật số.

Mạng Máy Tính & Mật Mã Học

Networking & Cryptography
  • Kiến trúc mạng & TCP/IP: Nắm vững mô hình OSI, cơ chế bắt tay 3 bước TCP, giao thức DNS, DHCP, HTTP/HTTPS, ARP.
  • Bảo mật mạng (Network Security): Phân tích gói tin mạng với Wireshark, hiểu luồng dữ liệu và phát hiện bất thường.
  • Mật mã học (Cryptography): Hiểu biết về thuật toán đối xứng (AES), bất đối xứng (RSA), băm (SHA, MD5), cơ chế chứng chỉ số SSL/TLS và PKI.

Phát Hiện Tấn Công & Web Security

Threat Detection (Blue Team)
  • Tư duy phòng thủ: Tập trung vào khâu Phát hiện (Detection) và Khoanh vùng hơn là đi khai thác.
  • Nhận diện các loại tấn công: Phishing, DoS/DDoS, ARP Spoofing, Man-in-the-Middle, Malware C2 traffic.
  • Web Application Security: Hiểu rõ OWASP Top 10 (SQLi, XSS, CSRF, IDOR, Broken Authentication) và các cơ chế phòng vệ WAF.

Công Cụ SIEM & Telemetry Monitoring

Wazuh, Sysmon, Splunk, ELK
  • Wazuh & Sysmon: Thu thập và theo dõi telemetry hệ thống, cấu hình agent giám sát tệp tin toàn vẹn (FIM) và tiến trình lạ.
  • Nền tảng SIEM: Làm quen với việc gom log, viết quy tắc truy vấn cảnh báo trên Splunk, ELK Stack, Wazuh Dashboard.
  • Incident Triage & Response: Quy trình phân loại mức độ nguy cấp của cảnh báo (Alert Triage), ghi nhận vé xử lý sự cố (Ticketing).
